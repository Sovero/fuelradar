# Changelog

Все заметные изменения проекта FuelRadar документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [0.1.5] — 2026-09-24

### Добавлено
- Сетевые списки АЗС: редактируемый список URL в админке — PUT
  `/admin/sources/network-lists` валидирует и сохраняет адреса в БД,
  при непустом списке активирует провайдер и ставит P1-задание сбора
  через воркер (без синхронных запросов из API); пустой список
  возвращает дефолт из `.env`; журнал аудита хранит только хосты
- Диагностические скрипты проверки геолокации в реальном приложении
  (`desktop/scripts/geo-*.py`, проверка через CDP)

### Изменено
- Desktop-приложение: версия 0.1.5 (пятый реальный прогон
  автообновления: 0.1.4 → 0.1.5)

## [0.1.4] — 2026-09-23

### Добавлено
- Дорожный маршрут: клик по подписи линии подсвечивает ближайший
  манёвр и перелетает к нему на карте

### Изменено
- Доступ: пользователи/роли/сессии удалены — приложение снова
  полностью открытое; подписка на события — Telegram-дайджест
- Маршрут в UI идёт по улицам (OSRM-совместимый роутер,
  `POST /api/v1/route/plan`), с дистанцией/ETA и списком манёвров
- Desktop-приложение: версия 0.1.4, CI-подпись стала опциональной

## [0.1.3] — 2026-09-20

### Добавлено
- Desktop-окно без рамки; Telegram-бот определяется через `/meta`
- Встроенный маршрут в приложении с дистанцией и ETA

### Изменено
- Desktop-приложение: версия 0.1.3

## [0.1.2] — 2026-09-19

### Добавлено
- Импорт из файлов: один понятный контракт файла, видимый в админке;
  загрузка заполненного CSV обогащения прямо из вкладки покрытия
  каталога; экспорт CSV кандидатов на обогащение
- Настоящий сетевой HTTP-адаптер списков АЗС
- RBAC (M16): bootstrap-админ, вход по паролю, cookie-сессии,
  управление ролями, журнал действий, rate-limit админ-API с аудитом
  неудачных попыток

### Изменено
- Дедупликация: пустые поля стороны считаются нейтральными,
  а не конфликтующими
- Маркеры станций на карте — канистра-стиль
- Геолокация: честный IP-fallback, когда местоположение устройства
  недоступно; резолвер токена фида и честная самопроверка фида
- Desktop-приложение: версия 0.1.2 — первый реальный прогон
  автообновления (0.1.1 → 0.1.2)

## [0.1.1] — 2026-09-12

### Добавлено
- Первое desktop-приложение (Electron + NSIS-установщик) с
  автообновлением через GitHub Releases
- Realtime: SSE-поток событий станции/наблюдений и настоящая
  доставка Web Push
- Поддержка цен на топливо end-to-end
- Прогноз появления/исчезновения топлива, heatmap, районы дефицита
- Поиск АЗС вдоль маршрута (Route Mode) и аналитика
- Автообновление: вкладка «Обновления» в настройках (версия +
  ручная проверка)

### Изменено
- `/auth/me` отвечает `200 {user: null}` для анонимных посетителей
