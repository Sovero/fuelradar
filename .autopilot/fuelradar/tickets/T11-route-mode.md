# 11 — Route Mode и коридор маршрута

**Волна:** 8
**Status:** ready

## Что должно заработать

Пользователь включает Route Mode, задаёт минимум две точки маршрута (с возможностью
добавить промежуточные), выбирает ширину коридора и получает станции в пределах
коридора. Линия видна в обеих реализациях карты. Без routing-провайдера интерфейс
честно называет это коридором по выбранным точкам.

## Из брифа, дословно

> «ROUTE_CORRIDOR — АЗС вдоль маршрута»
> «distance_from_route <= 5 km»
> «Система показывает станции в коридоре маршрута»

## Разделы спецификации

§22, §11, §16.2, шов публичного API.

## Критерии приёмки

- [ ] Публичный endpoint принимает polyline ≥2 валидных точек, corridor 0,5–50 км и стандартные топливные фильтры
- [ ] Расстояние считается до ближайшего сегмента, а не только до начала/конца
- [ ] Неверная polyline/corridor → русская 422; пустой результат валиден
- [ ] UI позволяет включить режим, выбрать/удалить точки и изменить коридор
- [ ] Route polyline отображается и в MapLibre, и в Yandex через общий `MapProviderProps`
- [ ] Старые карта/список/RouteButton работают без изменения публичных контрактов
- [ ] Backend unit/integration и frontend component tests проходят
