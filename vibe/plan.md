## Шаги

### Шаг 1: чистая функция buildPricePoints

- **Что:** `frontend/lib/priceHistory.ts` — `buildPricePoints(history)`: фильтр
  наблюдений с ненулевой ценой, сортировка по времени, счёт записей без цены
  перед каждой точкой, подпись `formatPrice(price, currency)` + источник +
  время + пометка пропусков; цвет линии — синий акцент `#2563eb` (деталь из
  spec §7).
- **Критерий выполненности:** функция возвращает точки только из ценовых
  наблюдений в хронологическом порядке; в подписи точки указаны цена/источник/
  время и «после N записей без цены», когда пропуск был.
- **Файлы:** `frontend/lib/priceHistory.ts` (новый)
- **Тесты шага:** `frontend/lib/priceHistory.test.ts` — пустая история,
  только записи без цены, одна цена, ≥2 цен с пропусками между ними.
- [ ] Выполнено

### Шаг 2: третий спарклайн в HistoryChart

- **Что:** в `HistoryChart.tsx` — блок цены после очереди: ≥2 ценовых точек →
  спарклайн + подпись «Цена во времени, N точек» (+ пометка о пропусках, если
  были); 1 точка → «По цене данных пока мало — только одно наблюдение.»;
  0 → блок не рисуется. Замокать `useStationHistory`/`useQueueHistory`/`useMeta`
  (vi.mock) — существующие тесты HistoryChart делают так же.
- **Критерий выполненности:** три состояния блока цены рендерятся по числу
  ценовых точек; существующие графики достоверности/очереди не меняются.
- **Файлы:** `frontend/components/station/HistoryChart.tsx`
- **Тесты шага:** `frontend/components/station/HistoryChart.test.tsx` —
  три состояния + отсутствие влияния на старые блоки.
- [ ] Выполнено
