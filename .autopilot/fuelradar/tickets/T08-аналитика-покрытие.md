**Требования:** R47, R48, R51, R52
**Blocked by:** 04
**Зона:** `backend/app/analytics/`
**Волна:** 5
**Status:** ready

## Что должно заработать

Покрытие данных по региону (АЗС обнаружено; с данными о топливе; частичные; нет данных;
Coverage %) — R51; покрытие по источникам до/после дедупликации (таблица «OSM: 185,
импорт: 76 … → 214 уникальных») — R52; Fuel Availability Index по видам топлива для города
(AI92 82/100 …) — R48; базовые агрегаты дефицита по истории: какие виды исчезают чаще,
какие сети стабильнее, длительность отсутствия, время восстановления — R47. Фоновый
пересчёт по расписанию + кэш; админ-endpoints в своей зоне (с X-Admin-Token из T05).

## Критерии приёмки

- [ ] Coverage по региону считается из station_current_status и совпадает с данными (тест)
- [ ] Покрытие по источникам показывает число записей каждого и число уникальных станций после дедупа
- [ ] Fuel Availability Index по видам топлива: 0–100 по городу/bbox
- [ ] Агрегаты дефицита: частота переходов в UNAVAILABLE, средняя длительность отсутствия, время восстановления (по сети)
- [ ] Пересчёт — фоновый (расписание), API читает кэш
- [ ] Админ-endpoints защищены (X-Admin-Token)
- [ ] Тесты: счётчики на фикстуре, индекс, агрегаты

## Швы для тестов

API-контракты аналитики (TestClient); агрегаты — чистые функции над выборкой наблюдений.
