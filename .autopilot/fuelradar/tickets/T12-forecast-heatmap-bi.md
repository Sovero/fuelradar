## Что должно заработать

На основе фонового AnalyticsSnapshot API отдаёт объяснимый трёхчасовой прогноз
и сравнение дефицита по городам/регионам. Пользователь включает heatmap текущей
доступности на карте, администратор видит размер выборки и честное предупреждение
о малом объёме пилотных данных.

## Из брифа, дословно

> «вероятность появления топлива в ближайшие 3 часа»
> «Прогноз обязательно помечается именно как прогноз»
> «районы дефицита»
> «зелёный — высокая доступность; жёлтый — снижение; красный — дефицит»

## Разделы спецификации

§23, §14, §16.2, шов AnalyticsSnapshot и публичного API.

## Критерии приёмки

- [ ] Прогноз возвращает направление, вероятность/ETA либо явную причину недостатка данных, `is_forecast=true`, метод и sample size
- [ ] HTTP endpoints читают только сохранённый snapshot, не сканируют историю
- [ ] BI группирует по city/region, сохраняет TTL-censoring и показывает размер выборки
- [ ] Heatmap включается отдельно от маркеров, обновляется по фильтрам и работает в обоих MapProvider
- [ ] Легенда и список дают текстовую альтернативу цвету; пустой/ошибочный analytics не ломает карту
- [ ] Существующие coverage/fuel-index/deficit endpoints обратно совместимы
- [ ] Backend и frontend тесты покрывают формулу, пустые данные и UI toggle
