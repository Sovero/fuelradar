# Спецификация: Выбор навигатора в карточке станции

> Заполнено по шаблону `.claude/skills/vibe-pipeline/templates/spec.md`
> (навык vibe-pipeline, шаг 2).

## 1. Цель

В карточке станции кнопка «Маршрут» должна открывать маршрут не только в
Яндекс.Картах (текущий fallback), а в любом из трёх внешних навигаторов —
Яндекс.Карты, 2ГИС, Google Maps — на выбор пользователя. Выбор запоминается.

## 2. Измеримый результат (Definition of Done)

- [ ] В карточке станции рядом с «Маршрут» есть выбор навигатора: Яндекс / 2ГИС / Google.
- [ ] 2ГИС строит корректный deep-link на координаты станции (добавлен в `buildRouteUrl`).
- [ ] Выбор навигатора сохраняется в localStorage и восстанавливается при следующем открытии.
- [ ] Дефолт (без сохранённого выбора) — Яндекс.Карты, как сегодня.
- [ ] Одиночный клик всегда открывает внешнюю карту (не ломать текущее поведение).
- [ ] Оба словаря i18n (ru/en) содержат все новые ключи.
- [ ] Юнит-тесты: `format.test.ts` (deep-links) и `NavigationPreference.test.tsx` (UI выбора) — зелёные.
- [ ] Typecheck и vitest зелёные целиком; фича проверена живьём в UI (DoD пользователя).

## 3. Скоуп

**Делаем:**
- `buildRouteUrl` поддерживает `"2gis"` (провайдер по координатам).
- Компонент выбора навигатора (сегмент-контрол 3 варианта) с сохранением в localStorage.
- Интеграция в `StationCard`: кнопка «Маршрут» открывает сохранённый (или дефолтный) навигатор.
- Ключи i18n ru+en.

**Не делаем (явно за границей):**
- Встроенную пошаговую навигацию (R80 — принципиальный отказ от embedded-навигации).
- Дополнительные провайдеры кроме трёх (Apple Maps, OsmAnd и т.п.).
- Изменения backend и внутреннего Route Mode (коридор/внутренняя карта не трогаются).
- Настройку навигатора в панели Settings (только локальный выбор у карточки).

## 4. Ограничения и инварианты

- Стек: только frontend; backend не затрагивается, контракты API не меняются.
- Инвариант R80: приложение никогда не строит встроенную пошаговую навигацию —
  только deep-link во внешний навигатор.
- Инвариант i18n: новый ключ существует в обоих словарях ru и en одновременно (R98i-подход).
- Справочники из `/meta` не затрагиваются.

## 5. Пользователь и сценарии

| Кто | Сценарий | Ожидаемый результат |
|-----|----------|---------------------|
| Водитель | Открывает карточку АЗС, жмёт «Маршрут» | Внешняя карта открывает маршрут до АЗС в последнем выбранном навигаторе |
| Водитель | Меняет навигатор в выпадашке у «Маршрут» | Выбор сразу сохранён; следующий «Маршрут» открывает его |
| Новый пользователь | Первый «Маршрут» без выбора | Открывается Яндекс.Карты (дефолт) |

## 6. Ответы на опрос (шаг 1)

- Фича? → «Навигация до АЗС» (deep link в Яндекс.Карты/2GIS/Google Maps с
  координатами АЗС; по итогам разведки скоуп сужен: buildRouteUrl и
  fallback-кнопка уже есть, добавляем выбор провайдера + запоминание).
- Что считаем «готово»? → «Тесты + живая проверка» (красные→зелёные тесты,
  typecheck/build чистые, фича проверена руками в живом UI).

## 7. Открытые вопросы

Нет — ответ на «каким должен быть deep-link 2ГИС» зафиксирован проверяемым
тестом в плане (шаг 1), а не оставлен «решим по ходу».
