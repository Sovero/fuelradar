## Что должно заработать

Три критических сценария брифа запускаются в Chromium одной командой и не требуют
реальных карт, Telegram/VAPID или внешней сети. При падении сохраняются trace и
screenshot, обычный успешный прогон не оставляет шумных артефактов.

## Из брифа, дословно

> «E2E — Критические пользовательские сценарии»
> «Пользователь открывает FuelRadar … выбирает AI-95 … видит статус и confidence … запускает маршрут»
> «AI95 отсутствует … нажимает “Следить” … получает push»
> «Нажимает “Сообщить” … GPS подтверждает … Observation сохраняется … Confidence пересчитывается»

§26 и бриф §126–§128.

## Критерии приёмки

- [ ] Playwright Chromium проходит поиск/геолокация/фильтр/карточка/маршрут
- [ ] Playwright проходит создание правила и появление уведомления в UI
- [ ] Playwright проходит пользовательский отчёт с GPS и подтверждением
- [ ] API и карта стабилизированы локальными mocks/fixtures, внешняя сеть и секреты не нужны
- [ ] Trace/screenshot только при сбое; селекторы основаны на ролях/доступных именах
- [ ] `npm run test:e2e` документирован; существующие vitest/typecheck/build остаются зелёными
