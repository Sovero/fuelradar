# Спецификация: История цены графиком в карточке станции

> Заполнено по шаблону `.claude/skills/vibe-pipeline/templates/spec.md`
> (навык vibe-pipeline, шаг 2). Рабочая область `vibe/` — одна фича за раз;
> документы предыдущей фичи (выбор навигатора) в истории git.

## 1. Цель

В карточке станции историю цены видно графиком, а не только текущим значением:
третий спарклайн в блоке «История» — цена во времени по наблюдениям.

## 2. Измеримый результат (Definition of Done)

- [ ] В блоке истории карточки третий спарклайн «Цена во времени», когда в истории ≥2 наблюдений с ценой.
- [ ] График строится ТОЛЬКО по точкам с ненулевой ценой; пропуски честны: в подписи точки указано, сколько записей без цены было пропущено перед ней.
- [ ] Ноль ценовых наблюдений → блок цены не рисуется вовсе; одно → честная строка «мало данных».
- [ ] Подпись точки: цена (formatPrice, валюта), источник, время, пометка пропусков.
- [ ] Юнит-тесты: чистая функция построения точек + HistoryChart (замоканные хуки) — красные до кода, зелёные после.
- [ ] E2E: сценарий с моком истории, содержащим цены — график виден, пропуски посчитаны.
- [ ] Typecheck + весь vitest + весь E2E зелёные; живая проверка в UI.

## 3. Скоуп

**Делаем:**
- `frontend/lib/priceHistory.ts` — чистая функция `buildPricePoints(history): SparklinePoint[]` (фильтр, сортировка, счёт пропусков, подписи).
- Интеграция в `HistoryChart.tsx`: третий блок спарклайна + честные состояния 0/1/≥2.
- E2E-спека `frontend/e2e/price-history.spec.ts` (мок истории с ценами поверх setupBase).

**Не делаем (явно за границей):**
- Backend: `/stations/{id}/history` уже отдаёт `price`/`price_currency` (T13) — не трогаем.
- Оси/масштаб/зум графика, интерактивные tooltip'ы поверх существующего Sparkline.
- i18n-ключи для подписей: HistoryChart сегодня говорит по-русски захардкожено («Достоверность наблюдений…», «Очередь…») — подписи цены в том же стиле, перевод блока истории — отдельная задача.

## 4. Ограничения и инварианты

- R17: история append-only — функция ничего не агрегирует и не сглаживает, только читает.
- Единицы не смешивать: цена — на своём спарклайне, не на шкале достоверности.
- Существующие графики (достоверность, очередь) не меняют поведение.
- Валюта — из наблюдения (`price_currency`, дефолт RUB как в StatusBadge).

## 5. Пользователь и сценарии

| Кто | Сценарий | Ожидаемый результат |
|-----|----------|---------------------|
| Водитель | Открывает карточку АЗС с историей цен | Видит третий спарклайн с ценой во времени и подписями «источник, время» |
| Водитель | Между двумя ценовыми наблюдениями были записи без цены | В подписи второй точки видно «после N записей без цены» |
| Водитель | У станции не измеряли цены | Блок цены отсутствует, существующие графики без изменений |

## 6. Ответы на опрос (шаг 1)

- Формат? → «Третий спарклайн» (как очередь, отдельный блок; ≥2 точек).
- Пропуски цены? → «Только ценовые точки», пропуски честны — счёт записей без цены в подписи точки.
- DoD? → «Юнит + E2E + живая проверка».
