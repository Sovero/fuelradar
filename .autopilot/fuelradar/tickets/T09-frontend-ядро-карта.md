## Что должно заработать

Next.js + React + TypeScript + Tailwind, слой карты абстрагирован (MapLibre GL + OSM tiles,
провайдер — конфигурация). Главный экран по макету §104: шапка (🔔 + настройки), выбор
топлива и радиуса, «Найти топливо рядом», табы Карта/Список/Избранное, быстрые фильтры
[92][95][100][ДТ]. Карта: маркеры цветом по выбранному топливу (🟢🟡🟠🔴⚪), составные
маркеры при нескольких топливах (95 ✅ / ДТ ❌), кластеры «47 АЗС». Карточка станции:
название, сеть, адрес, расстояние, время поездки, режим, топливо со статусами,
достоверность, время обновления, очередь, источники («почему система так считает» — R71),
графики истории (R46), кнопки Маршрут (внешний навигатор — R80), В избранное, Сообщить
(форма — в T10). Список с сортировками (расстояние/достоверность/наличие/очередь/время/
Score) и карточкой §107 (R74). Фильтры (топливо/сеть/доступность/достоверность/очередь/
радиус) + поиск; пустые состояния §108 с [20 км][30 км][Показывать вероятное наличие]
[Создать уведомление/Следить] (R75/R76); целевой ответ §142 (R93). Русский язык из
`/meta` (R98i, A02). PWA: манифест, service worker, офлайн-кэш карты/списка (R05).

## Из брифа, дословно

> «Главный пользовательский интерфейс — интерактивная карта», «🟢 нужное топливо есть… ⚪ нет данных»
> «маркер должен уметь показать состояние обоих: 95 ✅ / ДТ ❌»
> «близкие маркеры должны объединяться в cluster: 47 АЗС»

- [ ] Маркеры: цвет по выбранному топливу; ⚪ не означает «нет»; составной маркер при двух топливах
